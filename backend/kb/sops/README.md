# Sahayak SOP knowledge base

Prototype standard operating procedures that the agent retrieves while diagnosing and replying.
They describe how the **mock** Paytm systems in this repo behave and were written for the
hackathon prototype; they are not Paytm's internal policies. Regulatory references are to public
RBI / MeitY documents and should be checked against the source before being quoted to judges.

One file per topic; each `##` heading is one retrievable chunk.
